【学生说】They should be doing something. 怎么理解这个表达？

【老师说】They should be doing something.
核心意思：他们现在/当下本应该正在做某事（但实际上没在做，或你觉得他们没在做）。
1. 语法拆解
   should do：应该做（泛指、将来）
   should be doing：现在就应该正在做（强调此时此刻、当前阶段）
2. 最常用的两层含义
   ① 抱怨、不满
   他们本应该正在做某事，但你看他们没做。
   They should be working.
   他们现在本应该在工作。（潜台词：但他们在摸鱼）
   ② 合理推断
   根据情况，他们现在大概率正在做某事。
   It’s 10 PM. They should be sleeping.
   现在晚上10点，他们应该在睡觉。
   你原文里：
   They should actually be closing these off.= 他们现在就应该在把这些任务关掉/完结掉。（带一点：怎么还没关？）
3. 极简对比
   They should do it.
   他们应该做这件事。（什么时候做都行）
   They should be doing it.
   他们现在就应该正在做。（强调当下）
   需要我用你那段会议原文，帮你把所有 should be doing 这类口语句式都标出来并解释吗？

【学生说】所以， They should be doing 可以表达完全两个不同的意思，那怎么知道他们的具体意思呢？在某个场景下。

【老师说】你抓到了英语最关键、最实用的一点：They should be doing 确实有两个完全不同的意思，但在真实场景里，永远不会混淆。
我用最简单、最实战的方式告诉你怎么区分：
一、两个意思 + 一秒判断法
意思1：抱怨 / 指责 / 不满
他们本应该正在做（但没在做）
怎么判断？
语气：不满、提醒、批评
潜台词：But they are NOT doing it.
场景：工作、催促、问责
例句：
They should be working.
他们现在本应该在工作。（但在摸鱼）
意思2：合理推测 / 估计
他们现在应该正在做（我猜他们在做）
怎么判断？
语气：平静、猜测、推断
潜台词：I think they are doing it now.
场景：推测别人在干嘛
例句：
It’s 10 AM. They should be having a meeting.
现在10点，他们应该正在开会。（我猜）
二、一秒区分公式（超级好用）
看这一句：They should be doing X.
如果你心里想的是：→ “但他们没做！”= 抱怨/指责
如果你心里想的是：→ “我猜他们正在做”= 推测
场景 + 语气 = 100% 不会搞错。
三、回到你会议里的原句
They should actually be closing these off.
这里：
你在看任务没关闭
语气是提醒、不满
潜台词：但他们没关！
所以 100% 是意思1：抱怨/提醒= 他们现在就应该把这些关掉（但没做）。
四、极简总结（记住这句就够）
should be doing
有不满/催促 → 本应该在做（但没做）
是平静猜测 → 应该正在做（我猜）
