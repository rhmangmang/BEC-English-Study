因为 intend 可以表达 “当下的意图 / 设计原则”，而不只是未来计划。
类比中文你就秒懂：
* 		目前我们的定位是……
* 		目前我们的设计意图是……
* 		目前我们把它定义为……
这些都能用：currently, we intend … to be …
完全不矛盾。

4）如果 intend 是 “未来打算”，那才会怪
下面这种才奇怪、才冲突：❌ Currently, I intend to fix it tomorrow.（目前，我打算明天修。）
因为：
* 		currently = 现在
* 		intend to do = 未来动作时间对不上，才怪。
但你原文是：✅ currently + intend + sth + to be（定位 / 状态）= 目前的设计定位是……→ 时间完全匹配，不矛盾、非常自然。

5）整句最通顺的中文翻译（贴合 currently）
Like currently we intend them to be like not issues under the hood
翻译：而且就目前的设计来说，我们本意是不想让它们在底层被当成 issues。
这里 currently = 就目前而言、按现在的设计、目前我们的定位是

6）一句话总结（最关键）
* 		intend to do（未来动作）+ currently → 奇怪、矛盾
* 		intend sth to be（当前定位 / 设计）+ currently → 正常、自然、不矛盾
你原文属于第二种，所以 currently 放在前面完全没问题。

【学生说】这个文本提到了， We consider them work items, and we consider issues to be one type of work item. 这里的 consider 是两种用法，对吧？


【老师说】你看得非常准！这里确实是 consider 的两种最核心、最常用的结构，意思接近，但语法结构不一样，我给你拆得清清楚楚、一学就会。
原句里的两种 consider 用法
第一句：
We consider them work items.
结构：consider + 宾语 + 名词（不带 to be）
第二句：
We consider issues to be one type of work item.
结构：consider + 宾语 + to be + 名词

1）用法一：consider + 宾语 + 名词（最简洁、最地道）
We consider them work items.= 我们把它们看作工作项。= 我们认为它们是工作项。
结构：consider + sb/sth + 名词
特点：
* 		非常常用、非常口语、非常简洁
* 		不加 to be，直接跟名词

2）用法二：consider + 宾语 + to be + 名词（正式、清晰）
We consider issues to be one type of work item.= 我们认为 issue 是工作项的一种类型。
结构：consider + sb/sth + to be + 名词 / 形容词
特点：
* 		意思和上面完全一样
* 		只是更完整、更正式、更强调 “认定为”

3）最重要的结论：
这两句 意思完全一样，只是结构不同、简洁度不同
* 		We consider them work items.= We consider them to be work items.
* 		We consider issues to be one type of work item.= We consider issues one type of work item.
👉 to be 可加可不加，意思不变加 to be → 稍正式不加 to be → 更口语、更简洁

4）超级好记的对比（一模一样的意思）
* 		I consider him a friend.= I consider him to be a friend.我把他当朋友。
* 		We consider this table important.= We consider this table to be important.我们认为这张表很重要。

5）放回你原文，整段逻辑就通了
We consider them work items,（我们把它们看作工作项）and we consider issues to be one type of work item.（并且我们认为 issue 是工作项的其中一种类型）
作者想表达：
* 		所有这些东西 → 统称 work items
* 		issue 只是 work items 下面的一个子类型

一句话总结（你以后看到就秒懂）
consider + 宾语 + 名词= consider + 宾语 + to be + 名词意思完全一样，只是简洁度不同。
你这段英文里，作者就是前半句用简洁版，后半句用完整版，非常自然、非常地道。
