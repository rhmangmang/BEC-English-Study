## 1. 🎯 定向纠偏 (Flash Correct)

**类别**：不规则动词过去分词（`drive` / `run` / `take`）
**说明**：从 knowledge-gaps 🔴 Active 选取"不规则动词过去分词复发"类别，聚焦 3 题。

- **Round 1 (Type 3 虚拟语气 - `driven`)**:
  - 学生：`If it were not for the fact that the project was driven too heavily, we would not have been shortage of workforce.`
  - 评价：⚠️ `driven` ✅ 正确。但 Type 3 条件句应使用 `had been driven`（非 `was driven`）；主句 `shortage` 是名词不能直接做表语 → `wouldn't be short-staffed`。`if it were not for the fact that` 过于冗长。
  - 纠正建议：`If we hadn't driven the project too hard, we wouldn't be short-staffed now.`

- **Round 2 (现在完成时 - `run`)**:
  - 学生：`I did attend this kind of activity, but to be honest, it was ran too bad.`
  - 评价：🔴 **关键性错误** `was ran` ❌ → `was run` ✅。run-ran-**run**，被动语态必须用 `run`。另外 `ran`（动词）需副词 `badly` 修饰。
  - 纠正建议：`but to be honest, it was run too badly.`

- **Round 3 (现在完成时 - `taken`)**:
  - 学生：`all issues with the project have taken us three-month development time.`
  - 评价：✅ `taken` 正确。缺少"加起来"语义 → 可用 `combined have taken up`。`three-month` 做定语正确，但更自然的是 `three months of`。
  - 纠正建议：`All the issues with the project combined have taken up three months of our development time.`

**纠偏小结**：2.5/3 正确。`was ran` 为本次关键复发（过去分词 `run` 在被动语态中仍不稳定）。

### LP 1: `check into` (a hotel) — 新学 🆕

**来源**：10BEC — `he's checking straight into the hotel`
**含义**：固定短语动词，特指"办理酒店入住手续"，商务出行高频
**训练句式**：6/6 全部覆盖（肯定/否定/疑问/反义疑问/选择疑问/虚拟语气）

#### Round 1 (肯定陈述)
- 中文：我到了之后要先入住酒店，然后直接去会议室。
- 学生：`After I arrive, I'll check into the hotel before going straight to the office.`
- 评价：✅ 满分。`check into` ✅ + `straight` 副词 ✅ + 时间从句一般现在表将来 ✅ 用时态完全正确。

#### Round 2 (否定陈述)
- 中文：希望我在酒店不会碰到任何同事，我只想好好休息。
- 学生：`Hopefully, I will not run into any colleagues in the hotel. I just want to take a break.`
- 评价：🔴 **目标结构未使用**。学生跳过了 `check into`，直接用 `in the hotel` 替代。历史词组 `run into` 用得很地道 ✅，但目标语言点未命中 → **加练**。
  - **加练**：这次出差我不打算入住那家酒店，太贵了。
  - 学生：`I will not check into the hotel this trip. It is too expensive.`
  - 评价：✅ 否定式 `will not check into` 使用正确。`this trip` → 更完整是 `on this trip`/`for this trip`，但口语可接受。

#### Round 3 (特殊疑问句)
- 中文：这次出差你打算入住哪家酒店？
- 学生：`Which hotel do you plan to check into for this trip?`
- 评价：✅ 满分。`check into` 在疑问句中自然融入，介词悬空结构地道。`for this trip` 介词完整 ✅。

#### Round 4 (反义疑问句)
- 中文：你已经入住酒店了，对吧？
- 学生：`You've checked into the hotel, haven't you?`
- 评价：✅ 满分。完成时 `have checked into` ✅，反义疑问句极性 ✅（肯定主句 → 否定 tag）。

#### Round 5 (选择疑问句)
- 中文：你是打算住这家酒店还是换一家？
- 学生：`Will you check into this hotel or another?`
- 评价：✅ 满分。`Will you check into A or B?` 平行结构正确。

#### Round 6 (虚拟语气 Type 3)
- 中文：要是当时我没入住那家酒店，就不会遇到那个客户了。
- 学生：`If I had not checked into the hotel, I would not have run into the client.`
- 评价：✅ 满分 🔥。Type 3 公式完美 (`had + checked into` + `would have + run`)；**`run` 过去分词在这次用对了**——上次纠偏的成果显现！历史词组 `run into` 自然复用。

#### Quick Fire
- 场景：你到机场了，同事问你在哪里。告诉她你正要去入住酒店然后直去办公室。
- 学生：`I'm gonna check into the hotel and then go straight to the office.`
- 评价：✅ 满分。`gonna` 口语感强，`check into` + `go straight to` 自然流畅。

**LP 状态**：🟢 已固化 (6 句式 + QF 全部通过，零回退)

### LP 2: `set up` 被动进行时口语省略 — 新学 🆕

**来源**：10BEC — `The buffet won't be setting up until four thirty`
**含义**：物作主语 + 安排类动词 → 口语中用 `be doing` 代替 `be being done`
**训练句式**：5/6 覆盖（虚拟语气跳过——该语法点放入假设场景不自然）

#### 知识点讲解（根据学生要求先讲规则后练）
- 核心规则：物/活动作主语，动作为"安排/准备"类（set up/arrange/deploy/install），口语中 `be + doing` 可替代 `be being + done`
- 关键条件：主语必须是物（不是人）+ 动词含"安排/准备"语义
- 并列：`The system is deploying tonight` (口语缩略) = `The system is being deployed tonight` (完整语法)

#### Round 1 (肯定陈述)
- 中文：会场会在下午三点开始布置。
- 学生：`The conference center will be setting up 3 PM.`
- 评价：⚠️ `will be setting up` 物作主语 ✅，但 `3 PM` 前遗漏介词 `at` → `at 3 PM`。

#### Round 2 (否定陈述)
- 中文：自助餐不会在五点半之前开始布置。
- 学生：`The buffet won't be setting up before530。`
- 评价：✅ `won't be setting up` 正确，目标结构还原课文 ✅。`before530` 格式 → `before 5:30`。

#### Round 3 (特殊疑问句)
- 中文：会场什么时候开始布置？
- 学生：`When will the conference center be setting up?`
- 评价：✅ 满分。`will...be setting up` 疑问语序正确。

#### Round 4 (反义疑问句)
- 中文：自助餐会在四点半开始布置，是吗？
- 学生：`The buffet will be setting up at 4:30, will it?`
- 评价：🔴 **Tag 极性错误**。主句肯定 `will be` → tag 必须用否定 `won't it?`。`will it` ❌。knowledge-gaps 🔴 中已记录的"Tag 极性回退"问题再次出现。
  - 纠正：`The buffet will be setting up at 4:30, won't it?`

#### Round 5 (选择疑问句)
- 中文：会场是三点开始布置还是四点？
- 学生：`Will the conference center be setting up at 3 or 4?`
- 评价：✅ 满分。平行结构正确。

#### Quick Fire
- 场景：同事问你明天的活动安排。告诉她会场两点开始布置，自助餐四点半开始。
- 学生：`The conference center will be setting up at 2 PM tomorrow and the buffet will be setting up at 4:30 PM.`
- 评价：✅ 满分。两次使用 `will be setting up` 物作主语结构。

**LP 状态**：🟡 复用中（核心结构掌握，反义疑问句极性仍需注意）

### LP 3: `any longer` 在肯定条件句中 — 新学 🆕

**来源**：10BEC — `If they want to get to know each other any longer, they can use the hotel bar.`
**含义**：在肯定条件句中，`any longer` = "继续/再延续"，类似 `continue to / any further`。
**关键限制**：`any longer` 属非断定词（non-assertive），只能在否定/疑问/条件句中出现，**不能在独立肯定陈述句中使用**。
**训练句式**：5/6 覆盖（虚拟语气不适用）

#### Round 1 (条件句 + 肯定)
- 中文：如果你们想再坐一会儿，我可以晚点关灯。
- 学生：`If you want to stay any longer, I can switch off the lights later.`
- 评价：✅ 满分。`any longer` 在条件句中正确 ✅，`switch off the lights` 地道。

#### Round 2 (条件句 + 否定主句)
- 中文：如果客人想再住久一点，我们不会额外收费。
- 学生：`If customers want to stay any longer, we won't do extra charge.`
- 评价：⚠️ `any longer` 在条件句中用对了 ✅，但 `do extra charge` ❌ → `won't charge extra`（`extra` 是副词，修饰 `charge` 动词）。学生质疑 `extra` 是否有副词词性 → 搜索确认：牛津/朗文/柯林斯均列出 `extra` 的副词义项。

#### Round 3 (条件句 + 特殊疑问)
- 中文：如果电梯还要再修一阵子，我们该怎么办？
- 学生：`If the escalator needs repairing any longer, what should we do?`
- 评价：🔴 `needs repairing any longer` 语义不兼容。`needs repairing` 表达"需求"状态，不与 `any longer`（时间延伸）自然搭配。`take` 才是高频搭配(`take any longer to repair`)。学生质疑后纠正了关于 `take` 的解释 → **加练**。
  - **加练**：学生自行纠正为 `If it takes any longer to repair the escalator, what should we do?`
  - 评价：✅ 加练修复成功。`takes any longer to repair` 中的 `take` 表达"时间花费"，与 `any longer` 是最高频的自然搭配。

#### Round 4 (条件句包 + 反义疑问)
- 中文：如果客人还想再待久一点，我们可以把时间延长，对吗？
- 学生：`If guests want to stay any longer, we can extend the time, can't we?`
- 评价：✅ 满分。条件句保护了 `any longer` 的合法性，反义疑问句极性 `can't we?` 正确。
  - 注：上一轮学生尝试用肯定陈述句 `Guests want to stay any longer, don't they?` ❌ → 违反非断定词规则。该规则当时尚未向学生说明，属教学遗漏。

#### Round 5 (条件句 + 选择疑问)
- 中文：客人是想再待久一点，还是现在就结账？
- 学生：`Do guests want to stay any longer or just pay for the bill now?`
- 评价：⚠️ `stay any longer` 在疑问句中正确 ✅，但 `pay for the bill` 有冗余 → `pay the bill`（`pay` 及物用法：账单=直接宾语）。学生随后主动提问 `pay` vs `pay for` 的区别，已作答并搜索验证。

#### Quick Fire
- 场景：餐厅经理，客人饭后没走，同事问是否要催一下。
- 学生：`Well, if you guys want to stay any longer, it's okay.`
- 评价：✅ 满分。条件句 + `any longer` 自然流畅，`Well` 软化语气。

**LP 状态**：🟡 复用中（核心条件句用法掌握，非断定词限制仍需巩固）

### 🎭 Micro Role-play

**场景**：活动组织者，同事 Alice 问准备情况。需包含 `check into` + `set up` 两个语言点。

- 学生：`Well, after I check into the hotel, I'll go straight to the office and then prepare some materials. And I believe that the conference center will be setting up at 8 AM tomorrow. I think everything's going well. What do you think?`
- 评价：✅ ✅ 两个目标语言点都自然融入。`check into` 在时间从句中 ✅，`be setting up` 物作主语句式 ✅。`AM tomorrow morning` 略有冗余 → 取其一即可。整体叙述逻辑清晰、连贯性佳。

## 3. 🔴 不足与待强化 (Improvement Areas)

### 1. 不规则动词过去分词仍然脆弱
- **`was ran` ❌ → `was run` ✅**：第 4 次复发。`run` 的过去分词在被动态中自动转换为 `ran` 的惯性仍未根除。
  - 但 Type 3 虚拟中的 `would not have run` 后来用对了 ✅（LP 1 虚拟语气轮次）——隔离环境中可正确使用，自由输出时易回退。
- **Type 3 条件句结构**：`was driven` ❌ → `had been driven` ✅。`had + pp` 公式在独立造句中不稳定。

### 2. Tag 极性回退（第 N 次）
- `The buffet will be setting up at 4:30, will it?` ❌ → `won't it?`
- knowledge-gaps 中已多次记录但持续复发。本次是在新结构 `be setting up` 的语境中回退的——说明 Tag 极性问题**并非针对特定动词**，而是整个 Tag 系统的极性判断习惯未完全固化。

### 3. `any longer` 非断定词属性未掌握
- 学生尝试在独立肯定陈述句中使用 `Guests want to stay any longer` ❌。该规则属于非断定词范畴（类似 `anyone` 不在肯定句中单独使用）。
- 教学失误：**未在训练前说明该限制条件**，导致学生从条件句自然推演到肯定句时出现问题。

### 4. 词汇/搭配精准性
- `do extra charge` ❌ → `charge extra`（`extra` 的副词用法认知不足）
- `pay for the bill` ❌ → `pay the bill`（`pay` 及物 vs `pay for` 的规则未系统掌握）
- `needs repairing any longer` ❌ → `takes any longer to repair` / `is out of service any longer`（语义兼容性判断需加强）

### 5. 介词遗漏
- `will be setting up 3 PM` ❌ → `at 3 PM`

## 4. ✨ 亮点与进步

1. **`run into` 跨语言点自然复用 + Type 3 中正确使用 `run`** 🏆：LP 1 虚拟语气轮次中，学生用 `would not have run into the client`——Flash Correct 中纠过的 `was ran` 错误在 Type 3 环境下没有复发。说明**隔离环境下的纠正已经奏效**，自由输出仍需巩固。

2. **`check into` 全句式通关**：6 种句式全部一次或加练后通过，虚拟语气 + Quick Fire 零失误。

3. **主动质疑导师的讲解**：学生两次指出教学中的不准确（`extra` 副词词性 + `take` 不被视为"状态"的矛盾），推动教学更严谨。这在英语学习中是最有价值的能力之一。

4. **`straight` 副词多次自然使用**：在多个造句中自发用出，说明该词汇已在口语肌肉记忆中。
