## 定向纠偏记录

### 纠偏组 1: 不规则动词过去分词复发 (3 题)

#### 纠偏题 1
- **中文**: "如果当初他没接手那个任务，我们现在可能还在等审批呢。"
- **学生答案**: `If he had not taken on that mission, we could have been waiting for the approval.`
- **评价**:
  - 🎯 `taken` — 过去分词满分（take-took-taken）
  - 🔴 **Mixed Conditional 结果句**: `could have been waiting` → "现在还"是现在结果，不能用 `have been`，应为 `might still be waiting`
  - ⚠️ `mission` → `task`（偏军事感）
- **修正**: `If he had not taken on that task, we might still be waiting for approval.`

#### 纠偏题 2（首轮未过 → 加练）
- **中文**: "要不是你当时在会议上把那个问题提了出来，我们根本不会意识到风险。"
- **学生答案**: `If it had not been for you to put up with that question in the meeting, we would not have realized the risks.`
- **评价**:
  - 🎯 `put` 过去分词是 `put`（形态对但短语错）
  - 🔴 **短语混淆**: `put up with` = 忍受 ❌ → `bring up` = 提出 ✅。两个完全不同短语
  - 🔴 **语法结构**: `If it had not been for you to do` — 不成立，`If it had not been for` 后只能接名词/动名词
- **修正**: `If you had not brought up that issue in the meeting, we would not have realized the risks.`

#### 纠偏题 2（加练）
- **中文**: "就在今天早上，他开车送我去的机场——他以前从来没开过那条路。"
- **学生答案**: `Right in the today's morning, he drove me to the airport. he has never driven that road before.`
- **评价**:
  - 🏆 `drove` + `has never driven` — 过去式+过去分词双满分
  - 🔴 `Right in the today's morning` → `Just this morning`
  - 🔴 Comma Splice: 两个完整句子逗号连接
- **修正**: `Just this morning, he drove me to the airport. He had never driven that route before.`

#### 纠偏题 3
- **中文**: "这本该是早就被写进会议纪要里的——但当时没有人记下来。"
- **学生答案**: `This should have been written into the meeting summary. however, no one wrote it.`
- **评价**:
  - 🏆 `written` + `wrote` — 第三态+第二态双满分
  - ⚠️ `meeting summary` → `meeting minutes`（会议纪要标准说法）
  - 🔤 `however` 首字母应大写
- **修正**: `This should have been written into the meeting minutes. However, no one wrote it down.`

> **纠偏总结**: 3/3 通过。不规则动词过去分词全场零回退：`taken`、`driven`、`written`、`wrote`、`brought` 全部正确。`had went`/`have took` 型错误今日未触发 🏆。

## 造句训练记录

### 语言点 1: `back in + 时间`（45BEC 未记录 — 强调时间已过去 / 早在……那会儿）

#### Round 1 — 肯定陈述句（未过 → 加练 1 轮）
- **中文**: "早在去年第一次部署的时候，我们就碰到了不少意料之外的问题。"
- **学生答案**: `We have run into quite a few unexpected issues back in our first deployment last year.`
- **评价**:
  - ✅ `back in` 语义和位置正确
  - 🔴 **时态**: `have run into` ❌ → `back in + 具体过去时间` 是明确时间锚点，必须用一般过去时 `ran into`。完成时+过去时间不兼容——老问题复发
  - ⚠️ 过去分词 `run` 形态对，但过去式应为 `ran`
- **修正**: `Back in our first deployment last year, we ran into quite a few unexpected issues.`

#### Round 1（加练）— 肯定陈述句
- **中文**: "早在做上一家公司的时候，我们就意识到这个方案行不通了。"
- **学生答案**: `Back in our last company, we realized that this proposal is not gonna work.`
- **评价**:
  - ✅ `back in` 句首位置和语义正确
  - 🔴 **时态一致**: `realized`（过去）+ `is not gonna work`（现在）❌ → 从句也需回到过去视角：`would not work` / `was not going to work`
  - ⚠️ `Back in our last company` 听感怪 → `Back when we were at our last company`
- **修正**: `Back when we were at our last company, we realized that this approach was not going to work.`
- **备注**: 本轮学生主动提问 `road` vs `route` 的区别 → 随堂讲解：road 是具体道路，route 是完整路线。

#### Round 2 — 否定陈述句
- **中文**: "早在年初那会儿，管理层其实并没有批准这笔预算。"
- **学生答案**: `Back at the beginning of this year, the management didn't actually approve this budget.`
- **评价**:
  - 🏆 满分！`back at` + 时间点语义到位，`didn't approve` 一般过去时正确，`actually` 插入位置自然
- **备注**: 学生主动提问 `early this year` 中 `early` 的词性 → 随堂讲解：形容词修饰 `this year`。

#### Round 3 — 特殊疑问句（2 轮加练）
**首轮**:
- **中文**: "那个数据迁移工具到底早在什么时候就已经被废弃掉了？"
- **学生答案**: `Back when has this migration tool been duplicated?`
- **评价**:
  - 🔴 **词汇严重错误**: `duplicated` = 复制 ❌ → `deprecated` / `decommissioned` = 废弃 ✅
  - 🔴 `Back when` 不能引导疑问句
  - ⚠️ `this` → `that`
- **修正**: `When exactly was that data migration tool deprecated? Back in which release?`

**加练 1**:
- **中文**: "早在哪次发布中，那个旧的身份验证模块就被彻底弃用了？"
- **学生答案**: `Back in which release has the legacy identification module been completely deprecated?`
- **评价**:
  - 🏆 `Back in which release` — 疑问结构用对了
  - 🔴 时态: `has been deprecated` ❌ → `Back in which release` 指向具体过去时间点 → 必须 `was ... deprecated`
- **修正**: `Back in which release was that legacy identification module completely deprecated?`

**加练 2**:
- **中文**: "早在哪次代码评审里，这个问题就被 Charles 第一个指出来了？"
- **学生答案**: `Back in which code review was this issue pointed out by Charles?`
- **评价**:
  - 🏆🏆 **突破！** `was ... pointed out` — 在同题型第三次终于绕开"完成时+过去时间"，时态反射建立！
  - ⚠️ 漏译 `first`
- **修正**: `Back in which code review was this issue first pointed out by Charles?`

#### Round 4 — 反义疑问句
- **中文**: "早在六月份，那个安全问题就被解决了，不是吗？"
- **学生答案**: `Back in June, the security issue was fixed, wasn't it?`
- **评价**: 🏆 满分！时态 + Tag 极性双无瑕疵。

#### Round 5 — 选择疑问句
- **中文**: "那个兼容性问题早在 R15 就被发现了，还是到了 R16 才有人指出来？"
- **学生答案**: `Was the compatibility issue found back in R15 or was it pointed out until R16?`
- **评价**:
  - 🏆 `back in R15` 自然嵌入
  - 🔴 `until` 在肯定句中表"一直到……都在做"→ 中文"直到……才"用 `not ... until` 或 `only ... in`
  - ⚠️ R16 前漏 `in`
- **修正**: `Was the compatibility issue found back in R15, or was it only pointed out in R16?`

#### Quick Fire
- **场景**: 跟新同事聊遗留系统问题——这个问题早在半年前就被提出来了，当时没人当回事。
- **学生答案**: `Well, this issue was pointed out back in the last half year.`
- **评价**:
  - ✅ `back in` 用上了
  - 🔴 搭配: `back in the last half year` ❌ — `back in` 接具体时间点，不接时间段
- **地道版**: `Well, this issue was actually flagged about six months ago.`
- **备注**: 学生追问 `back in six months ago` 是否成立 → 随堂讲解：`back` 和 `ago` 不叠用，两者都是"往回看"。

> **`back in` 总结**: 5 句式 + QF 通关。最大成就：特殊疑问句 3 轮加练中成功破除"完成时+过去时间不兼容"老坑 🏆。时态反射从本轮后期开始稳定，后续无反发。

### 语言点 2: `communicate`（职场义：同步/告知）（45BEC 未记录）

#### Round 1 — 肯定陈述句
- **中文**: "早在变更生效前，运维那边就已经把停机时间同步给所有团队了。"
- **学生答案**: `Even before the change took effective, the infrastructure team had already communicated the timeline for shutting down the machine to all of the teams.`
- **评价**:
  - 🏆 `had communicated ... to all the teams` — 单向传达语义 + `to sb` 搭配正确
  - 🔴 `took effective` ❌ → `effective` 是形容词，需要名词 `effect`：`took effect`
  - ⚠️ `the timeline for shutting down the machine` → `downtime`（一个词）；`infrastructure team` → `ops team`
- **修正**: `Even before the change took effect, the ops team had already communicated the downtime to all teams.`
- **备注**: 学生追问 `all teams` vs `all of the teams` → 随堂讲解：两者皆可，`all teams` 更干脆。

#### Round 2 — 否定陈述句（加练 1 轮）
**首轮**:
- **中文**: "团队从未把这次变更的原因同步给业务方。"
- **学生答案**: `The team has never communicated the reason for this change.`
- **评价**:
  - 🏆 `communicated` 语义正确
  - 🔴 漏 `to sb`（给业务方）→ `communicate` 职场义完整结构是 `communicate sth to sb`
  - 🔴 `the reason` — 暗示只有一个原因，职场语境通常用复数 `the reasons`
- **修正**: `The team has never communicated the reasons for this change to the business side.`

**加练**:
- **中文**: "产品经理从未把这项决定的背景同步给我们。"
- **学生答案**: `The product manager has never communicated the background for this decision to me.`
- **评价**:
  - 🏆 `communicated ... to me` — 结构正确
  - ⚠️ `to me` → `to us`（中文"给我们"）；`background for` → `reasons behind`
- **修正**: `The product manager has never communicated the reasons behind this decision to us.`
- **备注**: 学生深度追问 `reasons for` vs `reasons behind` 的区别 → 随堂讲解：`for` 偏中性归属，`behind` 有画面感（藏在背后）。又追问为什么不用 `background` → 讲解：`background` 更多指履历/大环境，中文"决定的背景"用 `reasons behind` 更地道。

#### Round 3 — 特殊疑问句
- **中文**: "到底谁该把这次的进度变化同步给客户那边？"
- **学生答案**: `Who exactly should communicate the progress change to the client?`
- **评价**:
  - 🏆 `communicate ... to the client` + `Who exactly` 位置 — 双肌肉记忆
  - ⚠️ `progress change` → `status update`
- **修正**: `Who exactly should communicate the status update to the client?`
- **备注**: 学生追问 `change in progress` vs `change to the progress` → 随堂讲解：`in` = 变化发生在什么领域内，`to` = 变化作用于什么对象。

#### Round 4 — 反义疑问句
- **中文**: "要把当前的风险情况同步给全体干系人，不是吗？"
- **学生答案**: `Should communicate the current risk situation to all stakeholders, shouldn't we?`
- **评价**:
  - 🏆 `communicate ... to all stakeholders` + Tag `shouldn't we?` — 语义和极性双对
  - 🔴 **缺主语**: `Should communicate...` ❌ → 英语陈述句必须有主语 → `We should communicate...`
- **修正**: `We should communicate the current risk situation to all stakeholders, shouldn't we?`

#### Round 5 — 选择疑问句
- **中文**: "这些风险是要同步给全体干系人，还是先只跟核心团队对齐？"（植入 `align with` 🟡）
- **学生答案**: `Should these risks be communicated to all stakeholders? Or should we align with the core team first?`
- **评价**:
  - ✅ 两个语言点都用上了，意思清楚
  - ⚠️ 拆成了两个独立问句——选择疑问句更利落的做法是合并

#### Round 6 — 虚拟语气
- **中文**: "要是当初运维那边把停机时间同步给了所有人，我们那天就不会丢那么多数据了。"
- **学生答案**: `If the ops team had communicated the downtime to all people, we would not have had so much data loss at that day.`
- **评价**:
  - 🏆 `had communicated ... to` — Type 3 虚拟中结构依然稳固

#### Quick Fire

- **学生答案**: `You should have communicated the situation about the serious bug before.`
- **评价**:
  - ✅ `communicated the situation` — 语义正确
  - 🔴 场景理解偏差: 场景要求现在让他说出来，回答是事后批评（"你早该说"）
- **地道版**: `Can you communicate what you found to everyone?`

### 语言点 3: `not really like`（47BEC 未记录 — 不算是/算不上）

#### 概念讲解
- **学生初始理解**: "不太记得"
- **讲解**: `not really like` = `not really`（其实不）+ `like`（像是）= 弱化否定，给自己留余地、给对方留面子。对比直接否定（`isn't a problem`）vs 委婉否定（`isn't really like a problem`）。
- **理解检查**: "这不算一个 bug，更像是个体验问题" — 学生即兴回应 `This isn't really like a bug, more like an experience issue.` 🏆 当场掌握。

#### Round 1 — 否定陈述句
- **中文**: "这次产品积压任务里的混乱，其实算不上什么突发事件。"（植入 `backlog` 🟡）
- **学生答案**: `The turmoil in the product backlog items isn't really like an emergency.`
- **评价**: 🏆 满分！结构 + 语义 + 历史词组 `backlog` 自然植入。`turmoil` 是 47BEC 高级词，精彩。

#### Round 2 — 特殊疑问句
- **中文**: "为什么这种混乱给人的感觉算不上一个正式的积压审查问题？"（植入 `come across as` 🟢）
- **学生答案**: `Why does this turmoil come across as not really like a backlog review issue?`
- **评价**:
  - ✅ 两个词组都用了
  - 🔴 **结构冲突**: `come across as not really like` — `as` 和 `like` 功能重叠，叠加不自然
  - 🏆 `come across as` — 历史词组主动使用
- **修正**: `Why does this turmoil come across as something informal, not really like an official backlog review?`

#### Round 3 — 反义疑问句
- **中文**: "客户并没有真正察觉到这是个产品缺陷，算不上什么大问题，对吧？"（植入 `pick up on` 🟢）
- **学生答案**: `The client did not actually pick up that it is a product defect, it isn't really like a big issue, is it?`
- **评价**:
  - 🏆 `not really like ... is it?` — 结构和 Tag 双满分
  - 🔴 Comma Splice: 两个完整句子逗号连接
  - 🔴 时态: `that it is` → `that it was`（主句 `did not` 是过去时）
- **修正**: `The client didn't actually pick up on the product defect. It isn't really like a big issue, is it?`

#### Round 4 — 选择疑问句
- **中文**: "这算个缺陷，还是算不上大问题？"
- **学生答案**: `Is it like a defect, or isn't it really like a big issue?`
- **评价**:
  - ✅ `not really like` 第二半用上了
  - ⚠️ 平行结构偏散：两个完整问句拼在一起
- **修正**: `Is this really like a defect, or not really like a big deal?`
- **备注**: 虚拟语气跳过——AI 说明 `not really like` 放进 Type 2/3 假设句语义链断裂，学生同意。

#### Quick Fire
- **场景**: PM 说测试环境崩溃要拉 war room，其实只是 CI 跑了两次。你不想让他放大。
- **学生答案**: `It's not really like a big issue.`
- **评价**:
  - 🏆 结构和语义正确，反应即时
  - ⚠️ 缺安抚性解释——加上原因半句更自然
- **备注**: 学生追问 `a system outage` 含义 → 随堂讲解：`outage` = 宕机/停运（一段时间的不可用状态），vs `crash`（瞬间崩溃）。

> **`not really like` 总结**: 4 句式 + QF 通关。核心结构 `isn't really like + 名词` 已内化。特殊疑问句中 `come across as` 叠加 `not really like` 的结构冲突值得留意。

### 语言点 4: `initially`（47BEC 未记录 — 最初/一开始）

#### Round 1 — 否定陈述句（加练 1 轮）
**首轮**:
- **中文**: "那些积压需求最初并没有被当作缺陷来处理。"（植入 `backlog` 🟡）
- **学生答案**: `Those requirements in the backlog were not all considered as defects.`
- **评价**:
  - 🔴 **目标结构未使用**: 句子中无 `initially` — 关键性错误
  - 🏆 `backlog` — 历史词组自然植入
- **修正**: `Those requirements in the backlog were not initially treated as defects.`
- **备注**: 学生在加练前追问 `initially` vs `in the beginning` vs `at the beginning` 的区别 → 随堂讲解：意思几乎一样，`initially` 最灵活推荐；`in the beginning` 偏口语叙事；`at the beginning` 必须加 `of`。

**加练**:
- **中文**: "那些积压需求最初并没有被当作缺陷来处理。"
- **学生答案**: `Those requirements in the backlog were not initially considered as defects.`
- **评价**:
  - 🏆 `were not initially considered` — 副词位置（助动词后实义动词前）正确，修复成功
  - ⚠️ `considered as defects` → `treated as` 更贴合课文
- **修正**: `Those requirements in the backlog were not initially treated as defects.`

#### Round 2 — 特殊疑问句
- **中文**: "最初到底是谁该负责审核这些积压需求的？"
- **学生答案**: `Who exactly was initially responsible for reviewing these requirements in the backlog?`
- **评价**:
  - 🏆 `was initially responsible` + `Who exactly` + `backlog` — 三位一体满分
  - ⚠️ 漏译 `these`

#### Round 3 — 反义疑问句（加练 1 轮）
**首轮**:
- **中文**: "一开始并没有人察觉到那个术语上的混淆，对吧？"（植入 `pick up on` 🟢）
- **学生答案**: `Initially, no one picked up on the confusion of the terminology, didn't they?`
- **评价**:
  - 🏆 `initially` 句首位置 + `picked up on` 结构正确（名词短语非 `that` 从句—之前踩过的坑成功避开！）
  - 🔴 **Tag 极性回退**: `didn't they?` ❌ → `no one` 是否定主语，Tag 必须肯定：`did they?`。这是 `knowledge-gaps.md` 中已记录的顽固问题，今日首次触发
  - ⚠️ `the confusion of the terminology` → `the terminological confusion`
- **修正**: `Initially, no one picked up on the terminological confusion, did they?`

**加练**:
- **中文**: "那些积压需求一开始并没有被分类清楚，是吧？"
- **学生答案**: `Those requirements in the backlog were not initially clarified clearly, were they?`
- **评价**:
  - 🏆 `were they?` — Tag 极性修复成功！
  - 🏆 `initially` + `backlog` — 双植入
  - ⚠️ `clarified clearly` — 语义重复（clarify 含"清楚"）；"分类" = `classified`
- **修正**: `Those requirements in the backlog were not initially classified properly, were they?`

#### Round 4 — 选择疑问句
- **中文**: "这些需求最初是被归为缺陷，还是归为常规任务？"
- **学生答案**: `Were those requirements initially classified as defects or regular tasks?`
- **评价**: 🏆 满分！副词位置、平行结构、词汇 `classified as` 全部精准。

#### Round 5 — 虚拟语气
- **中文**: "如果一开始就把这些需求分类清楚了，术语就不会随着时间演变出这么大的混淆了。"（植入 `an evolution over time` 🟡）
- **学生答案**: `If we had classified these requirements clearly initially, the nomenclature would not have had so much confusion over time.`
- **评价**:
  - 🏆 `had classified` + `would not have had` — Type 3 时态匹配完全正确
  - 🏆 `nomenclature` + `over time` — 跨 session 复用 47BEC 高级词
  - ⚠️ `nomenclature would not have had so much confusion` — 搭配不自然（命名体系不会"拥有"混乱）
- **修正**: `If we had classified these requirements clearly from the start, there would not have been so much confusion around the nomenclature over time.`

#### Quick Fire（首轮未过 → 补一轮）
**首轮**:
- **场景**: 新同事问模块为什么叫 `issue-type issue` 这么绕——一开始草率决定，没人改。
- **学生答案**: `It was decided easily from the start, and later no one changed it.`
- **评价**:
  - 🔴 目标结构绕开：用了 `from the start` 而非 `initially`
  - ⚠️ `decided easily` → `decided casually / hastily`（草率≠容易）
- **修正**: `It was initially decided pretty casually, and then no one bothered to change it.`

**补一轮**:
- **场景**: 同事问为什么数据库里驼峰+下划线混用——一开始根本没统一过规范。
- **学生答案**: `The team didn't have the nomenclature initially.`
- **评价**:
  - 🏆 `initially` 句尾位置正确
  - 🔴 `didn't have the nomenclature` ❌ — 不能说"没有术语"，应是"没统一过"→ `never standardized` / `never agreed on`
- **修正**: `The team never standardized the nomenclature initially.`

> **`initially` 总结**: 5 句式 + QF 通关。Tag 极性回退（`no one ... didn't they?`）首次触发，加练后修复。Quick Fire 首轮绕开目标词，第二轮补上。`pick up on` 结构从之前的 `on that` 从句纠正为 `on + 名词短语`——跨 session 修复成功 🏆。
