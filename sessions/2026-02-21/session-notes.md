## 造句训练记录

### 语言点 1: at one point (曾经有一次 / 在过去某个阶段)
- **来源**: 25BEC-11s 原文 "...we played around with it at one point and had a draft for that..."
- **练习次数**: 5/5
- **掌握程度**: 高
- **详细记录**:
  1. ✅ 否定陈述句: "At one point, the client didn't want to sign this contract" — 完美
  2. ⚠️ 反义疑问句: "At one point, the product team wanted to cancel this feature actually, didn't they?" — `actually` 位置偏后，宜放谓语前 (`actually wanted`)
  3. ⚠️ 特殊疑问句: "Which platform did you track data metrics at one point?" — 缺介词 `on`；`at one point` 位置偏后；宜改为 `When did you first...?`
  4. ✅ 选择疑问句: "At one point, did you use an internal system or a third-party tool to track those metrics?" — 冠词全对，满分
  5. ⚠️ 虚拟语气 (Mixed): "If we had drafted a plan for this project at one point, we would now not be in much trouble." — `at one point` 在虚拟假设中语义冲突（它暗示事情确实发生过）；`now` 位置偏（宜放句尾）

### 语言点 2: have a draft for sth. (草拟某物的初稿)
- **来源**: 25BEC-11s 原文 "...had a draft for that probably about 5 months back..."
- **练习次数**: 5/5
- **掌握程度**: 高
- **详细记录**:
  1. ❌ 否定陈述句: "The team have not had a draft for any proposals before the meeting" — 时态错误: `before the meeting` 情境需过去完成时 `had not had`；`any proposals` → `any proposal`
  2. ✅ 反义疑问句: "The product manager did have a draft for this requirement, didn't they?" — 🌟今日最大亮点! `did have` 强调用法，自然精准
  3. ⚠️ 特殊疑问句: "when did you have a draft for this feature as early as?" — `as early as` 必须接具体时间，不可悬空；宜改 `When did you first have a draft for...?`
  4. ✅ 选择疑问句: "Did you have a draft for the whole system or just for a specific module?" — 满分
  5. ⚠️ 虚拟语气 (Mixed): "If someone had had a draft for this version, we would not need to start from the scratch" — `from the scratch` → `from scratch`（固定短语，无冠词）；结构满分

### 语言点 3: basically (口语弱化副词：软化语气·留余地)
- **来源**: 25BEC-11s 原文 "...the data team to basically get updated metrics..."
- **练习次数**: 5/5
- **掌握程度**: 高
- **详细记录**:
  1. ⚠️ 否定陈述句: "Basically, this plan is not so much complicated" — `not so much + 形容词` 错误；应用 `not that complicated`
  2. ✅ 反义疑问句: "Basically, the team just need more time, don't they?" — 🌟 `just` 精准捕捉"就是"语气，满分
  3. ✅ 特殊疑问句: "basically, why do you think we always avoid this issue?" — 几乎满分；`always avoid` → `keep avoiding` 更贴近"一直"
  4. ⚠️ 选择疑问句: "Basically, do you want to reduce costs or just to reduce process?" — `reduce process` → `simplify the process`（词汇错误）；缺冠词 `the`
  5. ⚠️ 虚拟语气 (Mixed): "Basically, if we had solved this problem, we would not be in so much trouble now" — 漏译"早点" → 缺 `earlier`；Mixed Conditional 结构满分

## 涵盖的关键概念

- **`at one point` 语义边界**: 暗示事情**确实曾经发生**，不适合放入虚拟假设从句（与"没发生"矛盾）
- **`as early as` 用法**: 修饰具体时间点（as early as February），不可单独悬空
- **`did + 动词` 强调用法**: 强调过去动作确实发生，如 `did have`、`did submit`
- **`from scratch`**: 固定短语，不加冠词
- **`reduce` vs `simplify`**: reduce=降低量；simplify=降低复杂度
- **`basically` 位置**: 句首（设定语气）或谓语前（弱化动作），均自然
- **`make progress`**: 固定搭配，不用 have progress
- **`go on doing` vs `keep doing`**: go on=继续做同一件事；"一直在做"用 keep doing / had been doing
- **叙述时态**: 讲述过去发生的故事，全篇统一用过去时态
- **虚拟语气条件句**: If 不可省略
