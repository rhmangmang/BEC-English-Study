## 语言点 1：`call + 宾语 + 名词补语`

### 概念判断

- **例句**: `The report calls it a work item.`
- **学生首次判断**: “同位语关系”
- **评价**:
  - 学生准确感知到 `it` 与 `a work item` 在语义上存在等同关系。
  - 句法术语不准确：`it` 是宾语，`a work item` 是宾语补足语，用于说明宾语被称为什么。
- **后续检查**: 在 `They call the plan a risk.` 中，学生回答“宾语补足语”。
- **结果**: 概念修正一次即通过。

### Round 1 — 肯定陈述句

- **中文**: “文档把分批发布称为主要问题。”
- **学生答案**: `The documentation calls releasing in batches a primary issue.`
- **目标结果**: 🏆 完全正确。
- **做对的地方**:
  - `releasing in batches` 正确充当宾语。
  - `a primary issue` 正确充当名词性宾语补足语。
  - `documentation` 可通过转喻作为命名行为的主语。
- **不足**:
  - 无实质语法或信息错误。
  - `primary` 比一般的“主要”语气略强，但仍在合理范围内。
- **推荐版本**: `The documentation calls releasing in batches a primary issue.`

### Round 2 — 否定陈述句：首次作答

- **中文**: “文档没把系统问题称为发布风险。”
- **学生答案**: `The document doesn't call the system issue a risky release issue.`
- **目标结果**: 🟡 结构正确，词义和名词短语需要修正。
- **做对的地方**:
  - `doesn't call + 宾语 + 宾补` 的否定骨架完全正确。
  - 没有把 `doesn't` 后的 `call` 错写成过去式或第三人称单数。
- **不足**:
  - `the system issue` 可以理解，但 `the issue with the system` 更自然清楚。
  - `a risky release issue` 表示“一个有风险的发布问题”，不等于“发布风险”。
  - 目标名词应为 `a rollout risk` 或 `a release risk`。
- **推荐版本**: `The document doesn't call the issue with the system a rollout risk.`

### Round 2A — 否定陈述句修正

- **学生答案**: `The document doesn't call the issue with the system a rollout risk.`
- **目标结果**: 🏆 修正完全正确。
- **做对的地方**:
  - `the issue with the system` 与 `a rollout risk` 均准确。
  - 目标结构与否定形式完整保留。
- **不足**: 无。

### Round 3 — 特殊疑问句

- **中文**: “文档把分批发布称为什么？”
- **学生答案**: `What does the document call releasing in  batches?`
- **目标结果**: 🏆 语法与目标结构正确。
- **做对的地方**:
  - `what` 正确询问宾语补足语。
  - `does + 主语 + call` 语序正确。
  - `releasing in batches` 完整保留为宾语。
- **不足**:
  - `in  batches` 中出现两个空格，仅为书写格式问题。
- **推荐版本**: `What does the document call releasing in batches?`

### Round 4 — 附加问句：首次作答

- **中文**: “文档称它为系统问题，不是吗？”
- **学生答案**: `The document calls it a system issue, does it?`
- **目标结果**: 🔴 主句正确，Tag 极性错误。

  - `calls it a system issue` 的宾语与宾补正确。
  - 主句一般现在时和第三人称单数形式正确。
- **不足**:
  - 肯定主句后应使用否定附加问句：`doesn't it?`
  - 这是目标句式层面的错误，因此增加同类型修正轮。
- **正确版本**: `The document calls it a system issue, doesn't it?`

### Round 4A — 附加问句加练

### Quick Fire 1/3 — `as opposed to`

- **目标结果**: 🟡 目标结构正确，冠词取决于是否作为正式标签。
- **做对的地方**:
  - `call + 宾语 + 名词补语` 使用正确。
  - `as opposed to` 正确表达“而非”。
- **不足**:
  - 默认按普通类别理解时，`task` 和 `work item` 都是单数可数名词，应加冠词。
  - 若明确指正式 UI 标签，应写作 `“Task”` 和 `“Work Item”`，用引号和大写标明标签身份。
- **推荐版本**: `The document calls it a task as opposed to a work item.`

### Quick Fire 2/3 — 被动结构：首次作答

### Quick Fire 3/3 — 多页面命名：首次作答

- **场景**: 四个页面命名不一致，其中三个称为推广方案，剩下一个称为任务。

- **做对的地方**:

  - 两次主动使用 `call it...`。
  - `releasing in batches` 历史词组调用成功。
- **不足**:
  - `name ... differently` 生硬，应说 `use different names for...`。
  - `release plan` 未使用课文目标 `rollout plan`。
  - `release plan` 和 `task` 作为普通类别均缺冠词。
  - `the rest one` 不成立，应为 `the remaining one` 或在两组对比中用 `the other one`。
- **推荐版本**: `Four pages use different names for releasing in batches: three of them call it a rollout plan, while the remaining one calls it a task.`

  - `the other one` 正确指四页中剩余的一页。
- **不足**:
  - 无实质错误。

  - 原意是“团队支持分批发布”，却写成 `it can support releasing in batches`，变成“改动能够促进分批发布”。

  - 题目要求一句话，实际写成两句。

### Quick Fire 1A/2 — 语义关系修正

- **学生答案**: `Although the team supports releasing in batches, I still think this change deserves a formal rollout plan, because it will impact all the users.`

- **做对的地方**:
  - `the team supports...` 恢复了正确施事者。
  - `this change deserves...` 目标结构正确。
  - 已按要求合并成一句。
- **不足**:
  - 再次漏掉 `updates`。
  - `because` 前通常不加逗号。
  - 泛指全体用户时 `all users` 更简洁；`all the users` 更像特定的一组用户。
- **推荐版本**: `Although the team supports releasing updates in batches, I still think this change deserves a formal rollout plan because it will impact all users.`

### Quick Fire 2/2 — 首次提交

- **场景**: 团队支持把 5 项更新分 3 批发布；当前改动只影响一个内部页面，因此不值得单独制定推广方案。要求一句话并保留全部数量。

  - `5 updates`、`3 batches` 和单个内部页面的信息均有体现。

  - 三句之间逻辑清楚。
- **不足**:
  - 题目要求一句话，实际拆成三句。
  - `only affects an internal page` 的 `only` 可能限定“只做影响这一动作”；表达“只影响一个页面”应说 `affects only one internal page`。

### Quick Fire 2A/2 — 一句话合并修正

- **学生答案**: `The team supports releasing 5 updates in 3 batches, but the current change affects only one internal page, so it doesn't deserve a separate rollout plan.`
- **目标结果**: 🏆 完全正确，Quick Fire 完成。
- **做对的地方**:
  - 用 `but` 和 `so` 把三层逻辑自然合并为一句。
  - `affects only one internal page` 的限定范围准确。
  - 全部数量、动作、对象和结果均保留。
- **不足**:
  - 无实质错误；正式连续文本可拼写 `five`、`three`，口语训练不扣分。

## Micro Role-play：`call` + `deserve` 综合复用

### 场景

四个文档页面命名不一致：三个称它为推广方案，剩下一个称它为任务。这项改动解决了新系统的两个问题并影响所有用户，因此值得一套清晰的推广方案。

### 首次提交

- **学生答案**: `4 document pages have different names for it, 3 of them call it a rollout plan, and the remaining one calls it a task. this change resolves two issues with the new system, and affects all users, so it deserves a clear rollout plan.`
- **目标结果**: 🟡 两个核心语言点均命中，但书面句子边界错误。
- **做对的地方**:
  - `call it a rollout plan / a task` 正确复用语言点 1。
  - `deserves a clear rollout plan` 正确复用语言点 2。
  - `issues with the new system` 历史语言点使用准确。
  - `4`、`3`、剩余一个、`two issues`、`all users` 全部保留。
- **不足**:
  - `...names for it, 3 of them...` 用逗号连接两个完整分句，构成 Comma Splice。
  - 第二句句首 `this` 应大写。
  - 同一主语 `This change` 连接两个谓语时，`and affects` 前不需要逗号。
  - `document pages` 可理解，但 `pages in the documentation` 略自然。

### 修正提交

- **学生答案**: `4 document pages have different names for it: 3 of them call it a rollout plan, and the remaining one calls it a task. This change resolves two issues with the new system and affects all users, so it deserves a clear rollout plan.`
- **目标结果**: 🏆 完全修正，Micro Role-play 通过。
- **做对的地方**:
  - 冒号成功修复 Comma Splice。
  - `This` 句首大写已修正。
  - 删除 `and affects` 前多余逗号，两个并列谓语连接自然。
  - 两个目标语言点和全部信息继续完整保留。
- **不足**:
  - 无实质错误；`Four pages in the documentation` 比 `4 document pages` 略自然。

## 无提示延迟复测：`entail`

### 复测 1 — 未主动召回目标词

- **中文**: “这套推广方案具体会涉及哪些界面改动？”
- **学生答案**: `What specific changes in UI will be involved in this rollout plan?`
- **目标结果**: 🔴 意思接近，但无提示复测未通过。
- **做对的地方**:
  - 特殊疑问句基本结构正确。
  - `specific changes`、`UI`、`rollout plan` 三项核心信息均保留。
- **不足**:
  - `changes in UI` 应为复合名词 `UI changes`，或写成 `changes in the UI`。
  - `be involved in` 让“改动”成为被包含项，虽可理解，但不如“方案主动涉及改动”直接。
  - 最关键的是没有无提示召回历史目标词 `entail`。
- **能力判断**: `entail` 尚未达到自动化主动输出，继续保持 🟡。

### 概念辨析 — 使用场景

- **学生提问**: “`entail` 的使用场景？”
- **首次理解检查**: 学生回答“不知道”。
- **讲解结论**:
  - `entail` 用于某项计划、决定、角色或变化**必然包含、涉及或带来**的工作、要求或后果。
  - 常接名词或动名词：`entail additional costs`、`entail updating the UI`。
  - 不接 `to do`：`entail to update` ❌。
  - 与 `include` 相比，`entail` 更强调必要组成或必然后果。
- **理解检查**: 对 `Changing the term will entail retraining the support team.`，学生选择 B——“更改术语必然会涉及重新培训支持团队”。
- **结果**: 概念理解通过。

### 复测 2 — 召回词汇但主被动关系生硬

- **学生答案**: `What specific changes in the UI will be entailed in this rollout plan?`
- **目标结果**: 🟡 成功召回词汇，但语义角色仍沿用被动模板。
- **做对的地方**:
  - 已修正为 `changes in the UI`。
  - 成功使用 `entail`。
- **不足**:
  - `be entailed in this rollout plan` 并非绝对不成立，但在该问句中生硬。
  - 自然逻辑是“这套方案涉及哪些改动”：`this rollout plan` 应作 `entail` 的主语，改动作宾语。
- **语法映射**: `The rollout plan entails UI changes.` → `What UI changes will the rollout plan entail?`

### 复测 3 — 主动结构修正

- **学生答案**: `What specific changes in the UI will this rollout plan entail?`
- **目标结果**: 🏆 修正正确。
- **做对的地方**:
  - `this rollout plan` 正确作为 `entail` 的主语。
  - `what specific changes in the UI` 正确前置为疑问宾语。
  - `will + entail` 动词形式正确。
- **不足**:
  - 本句经过词义讲解和两轮结构提示后完成，不能算无提示主动召回成功。
- **最终状态**: 🟡。理解已恢复，但需要隔场再次无提示测试。

本轮完成了 64BEC 补扫中的两个高价值新语言点：`call + 宾语 + 名词补语` 与 `deserve + noun`。学生已经能在陈述、否定、特殊疑问、附加问句、选择问句、假设句、Quick Fire 和 Micro Role-play 中调用它们。真正需要继续修复的并非目标骨架，而是复杂输出中的信息忠实度、Comma Splice、句首格式和语义角色分配。`entail` 的词义理解已经恢复，但无提示召回和主动结构仍未自动化，因此维持 🟡；`rely on sb to do` 的延迟复测尚待完成。
