## 造句训练记录

### 语言点 1: mass-add (批量添加)

#### Round 1 — 带否定的陈述句
- **中文**: “由于目前系统权限的限制，那个管理员并没有把这些特定的联系人批量添加到营销活动中。”
- **学生答案**: `Because of the current limitation of the system's permission, the admin didn't mass-add the specific contacts into the campaign.`
- **评价**: 
  - ✅ `mass-add` 连字符使用正确。
  - **地道性建议**: 课文中使用的是 `mass-add ... **to** a campaign`。`into` 虽然可理解，但 `to` 在 CRM 系统语境下更标准。

#### Round 2 — 特殊疑问句
- **中文**: “由于那些线索的数据不完整，管理员到底是如何在没有手动操作的情况下批量添加他们的？”
- **学生答案**: `Since those lead data is not complete, how did the admin mass-add them without manual operation?`
- **评价**:
  - ✅ `Since` 开头逻辑性强。
  - **🔴 单复数/代词冲突**: `those` (复数) 修饰 `lead data` (在此被视为单数 is)。建议改为 `Since the data for those leads is incomplete...`。

#### Round 3 — 反义疑问句
- **中文**: “管理员已经在报表里把那些联系人批量添加好了，不是吗？”
- **学生答案**: `The admin has mass-added those contacts in the reports, haven't they?`
- **评价**: 🏆 **完美修复昨日错误！** 成功匹配了性中立单数 `admin` 对应的复数形式 Tag `haven't they?`。

#### Round 4 — 选择疑问句
- **中文**: “由于本周我们要处理这么多线索，我们是应该手动添加每一位成员，还是利用报表进行批量添加？”
- **学生答案**: `Since we're gonna handle so many leads this week, should we add every member manually or mass-add them by using the reports?`
- **评价**: 🏆 **职场感极佳！** `gonna` 的使用非常地道，平行结构 `add... or mass-add` 均衡。

#### Round 5 — 虚拟语气 (Mixed Conditional)
- **中文**: “如果那个管理员昨天确实批量添加了那些特定的记录，我们现在就不必手动处理这么多数据了。”
- **学生答案**: `if the admin had actually mass added those specific records yesterday, we would not have to handle so much data manually.`
- **评价**:
  - ✅ 混合虚拟语气时态骨架完全正确。
  - **🔴 严师提醒**: 在最后一轮漏掉了 **`mass-add` 的连字符**。

### 语言点 2: allows you to / allow you to (让你可以 / 供……使用)

#### Round 1 — 带否定的陈述句
- **中文**: “由于那个特定的权限限制，这个描述字段并不能让你为你的线索添加任何内部备注。”
- **学生答案**: `Because of the specific permission restriction, the description field does't allow us to add any internal comments for your lead.`
- **评价**:
  - ✅ `internal comments` 词汇选用地道。
  - **笔误**: `does't` 漏掉了 **n**。

#### Round 2 — 特殊疑问句
- **中文**: “既然我们已经创建了这个新活动，这个状态字段到底能让你选择哪种类型的当前状态？”
- **学生答案**: `Since we've already created this new campaign, what type of current state does the state field allow us to choose?`
- **评价**:
  - ✅ 疑问语序正确。
  - **术语规范**: 建议将 `state` 统一为 CRM 标准术语 **`status`**。

#### Round 3 — 反义疑问句
- **中文**: “预算和实际成本（字段）允许我们定义 ROI 跟踪的信息，不是吗？”
- **学生答案**: `The budget field and the actual cost field allow us to define the information for ROI tracking, don't they?`
- **评价**: 🏆 **满分！** 复数主语匹配 `don't they`，极性处理完美。

#### Round 4 — 选择疑问句
- **中文**: “是描述字段（Description field）允许你添加内部备注，还是类型字段（Type field）允许你这么做？”
- **学生答案**: `does the description field or the type field allow you to add internal comments?`
- **评价**: 🏆 **简洁地道**。`does ... allow` 处理 `A or B` 的单数一致性非常专业。

#### Round 5 — 虚拟语气 (Mixed Conditional)
- **中文**: “如果当初那个自动化工具（Automation tool）允许管理员根据特定标准来分配成员，我们就不会面临现在的这些问题了。”
- **学生答案**: `if the automation tool had allowed the admin to assign members based on certain criteria, we would not face these problems now.`
- **评价**: 🏆 **教科书级 Mixed Conditional**。时态切换无懈可击。

### 语言点 3: fill out (填写整份表单 / 信息)

#### Round 1 — 带否定的陈述句
- **中文**: “由于他今天要给这么多客户打电话，那个管理员并没有为这条特定的线索填写基本信息。”
- **学生答案**: `since he's going to call so many customers today. The admin has not fill out basic information for the specific lead.`
- **评价**:
  - **🔴 严重语法错误 (回退)**: `has not **fill**` ❌。`has` 后面必须接过去分词 **`filled`**。
  - **结构问题**: `Since` 引导的从句不应独立成句。

#### Round 2 — 特殊疑问句
- **中文**: “既然你是管理员，你为什么还没有为那个营销活动填写基本信息？”
- **学生答案**: `Since you are the admin, why haven't you filled out the basic information for that campaign?`
- **评价**: 🏆 **即时修复**。成功使用了 `filled`。

#### Round 3 — 反义疑问句
- **中文**: “管理员还没有填写那些特定的基础（营销活动）信息，不是吗？”
- **学生答案**: `The admin has not filled out the specific basic information for that campaign, haven't they?`
- **评价**: 
  - **🔴 极性回退警报**: `has not` (前否) -> 应接 `have they?` (后肯)。你连用了两个否定。

#### Round 4 — 选择疑问句
- **中文**: “是由于这个新活动的负责人不在（off），所以你替他填写了基本信息，还是那个管理员已经帮你填好了？”
- **学生答案**: `have you filled out the basic information for him because the person who's responsible for this new campaign is off or has the admin filled out them for you?`
- **评价**:
  - **🔴 代词位置错误**: `filled out them` ❌。代词必须放中间：**`filled it out`**。
  - **🔴 指代错误**: `information` 不可数，应用 `it` 而非 `them`。

#### Round 5 — 虚拟语气
- **中文**: “如果那个管理员昨天确实在这个线索上填写了所有的基本信息，我们现在就可以点击保存按钮了。”
- **学生答案**: `If the admin had actually filled out all the basic information on the lead, we would be able to click the save button.`
- **评价**: 🏆 **满分结尾**。

### 语言点 4: based on certain criteria (基于特定标准)

#### Round 1 — 带否定的陈述句
- **中文**: “由于系统当前存在 bug，它并没有基于特定标准来过滤那些重复的线索。”
- **学生答案**: `Because the system has some bugs for now, it doesn't filter those duplicated lead, based on certain criteria.`
- **评价**:
  - **🔴 单复数一致性**: `those` -> **`leads`** (复数)。

#### Round 2 — 特殊疑问句
- **中文**: “既然我们要推出的是新系列，管理员到底是基于什么特定标准来把这些旧线索添加到我们的活动中的？”
- **学生答案**: `Since we're going to launch our new series, based on what kind of certain criteria have the admin added these old leads to our campaigns?`
- **评价**:
  - **🔴 主谓不一致**: `the admin` (单数) -> **`has`**。

#### Round 3 — 反义疑问句
- **中文**: “系统并没有基于特定标准来自动更新这些线索的状态，不是吗？”
- **学生答案**: `The system didn't automatically update the status of these leads, based on certain criteria, did it?`
- **评价**: 🏆 **极性翻转成功**。`didn't` -> `did it?` 表现稳定。

#### Round 4 — 选择疑问句
- **中文**: “这些新成员是手动添加的，还是系统基于特定标准自动添加的？”
- **学生答案**: `have these new members been added manually or automatically based on certain criteria?`
- **评价**: 🏆 **结构规范**。被动语态运用自如。

#### Round 5 — 虚拟语气
- **中文**: “如果管理员当初基于更灵活（flexible）的特定标准来过滤线索，我们现在可能就会有更多高质量的商机了。”
- **学生答案**: `If the admin had filtered the leads based on more flexible certain criteria, we would be able to have more high-quality opportunities.`
- **评价**: 🏆 **全胜通关**。

## 重点纠错与不足总结 (Knowledge Gaps)

| 涉及知识点 | 原始错误 | 纠正/改进方向 | 严重程度 |
| :--- | :--- | :--- | :--- |
| **🔴 Tag Question 极性** | `has not ... haven't they?` | **前否后肯**：`has not ... have they?` | **高 (顽固回退)** |
| **🔴 代词位置 (Phrasal Verbs)** | `filled out them/it` | 代词必放中间：**`filled it out`** | **高 (新发现)** |
| **🔴 单复数一致性** | `those lead`, `have the admin` | 必须养成扫描主语/修饰词单复数的肌肉记忆 | **中** |
| **information 指代** | `filled them out` | information 是**不可数名词**，指代只能用 **`it`** | **中** |
| **过去分词遗漏** | `has not fill` | 完成时必须跟过去分词 **`filled`** | **中 (粗心)** |

## 识别出的知识差距
- **反义疑问句极性**：这是目前的“一号敌人”。在处理“否定主句”时，大脑倾向于顺延否定逻辑，需建立“见到 not，Tag 必掉 not”的反射。
- **代词位置语感**：`fill out` 类的短语动词，代词夹心结构还不算本能。
- **单复数扫描**：在长句中容易忽略 `those/leads` 的对应。
